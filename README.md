# reactivity-examples

To install dependencies:

```bash
bun install
```

To run:

```bash
bun dev
```

This is just to show off the differences between React, Solid, and Svelte. Not a serious project.

When you start it, the projects will be available at:

- React: http://localhost:5175
- Solid: http://localhost:5174
- Svelte: http://localhost:5173
